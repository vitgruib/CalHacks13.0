# 13. Fear of keyword-based termination; self-censoring grants

**Status:** new (3 independent sources) — context only; avoid building a
"how to evade screening" feature
**One-liner:** Researchers believe automated keyword searches flag grants for
termination, so labs hunt for "banned word" lists and rewrite proposals.
